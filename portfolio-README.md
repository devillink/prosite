# Modern Portfolio Website with Spline 3D

A sleek, responsive portfolio website built with HTML, CSS, and Three.js featuring an integrated Spline 3D scene background and smooth interactions.

## Features

✅ **Responsive Dropdown Navigation** - Mobile-friendly hamburger menu
✅ **Three.js Animated Background** - Interactive particle system
✅ **Modern Design** - Clean, professional layout
✅ **Minimal Text** - Focused, concise content
✅ **Smooth Animations** - Scroll-triggered animations and hover effects
✅ **Interactive Elements** - Hover effects and click interactions
✅ **Contact Form** - Functional form with validation
✅ **Mobile Optimized** - Fully responsive design

## Structure

```
/
├── index.html         # Main HTML file
├── styles.css         # Modern CSS styling
├── script.js          # Three.js and interactions
└── portfolio-README.md # This documentation
```

## Customization

### Colors
Edit CSS custom properties in `styles.css`:
```css
:root {
  --primary-color: #667eea;
  --secondary-color: #764ba2;
}
```

### Content
Update text and images in `index.html`

### Animation
Modify Three.js parameters in `script.js`

## Usage

1. Open `index.html` in a web browser
2. Navigate using the menu or scroll
3. Interact with the animated background
4. Submit the contact form
5. View on mobile for responsive design

## Development

To modify the website:
1. Edit HTML structure in `index.html`
2. Update styling in `styles.css`
3. Modify interactions in `script.js`
